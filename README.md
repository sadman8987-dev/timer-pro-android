# Timer Pro

تطبيق أندرويد بواجهة عربية لساعة الإيقاف والعد التنازلي، ويعمل دون اتصال بالإنترنت.

## المميزات
- ساعة إيقاف مع تسجيل اللفات.
- عد تنازلي بالساعات والدقائق والثواني.
- إيقاف مؤقت واستكمال وإعادة ضبط.
- تنبيه صوتي عند انتهاء العد التنازلي.
- لا يحتاج إلى اتصال بالإنترنت.

## تنزيل APK
يتم بناء نسخة Debug APK تلقائيًا عبر GitHub Actions عند كل تحديث على فرع main، أو يدويًا من تبويب Actions عبر تشغيل **Build Timer Pro APK**.
بعد نجاح التشغيل افتح آخر تشغيل ناجح وحمّل Artifact باسم **Timer-Pro-APK** ثم فك الضغط وثبّت app-debug.apk.

## المتطلبات
Android 6.0 أو أحدث.
